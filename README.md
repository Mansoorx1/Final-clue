
# 🗝️ Tech Fest Treasure Hunt – Clue Page

A clue-delivery page built for the treasure hunt event at our department's tech fest. After each round, teams log in to unlock their next clue.

🔗 **Live site:** https://mansoorx1.github.io/Final-clue/

## How It Works
1. Enter your **team number** and **password**.
2. Press **Unlock clue**.
3. Your clue for that round is revealed.

## Features
- Team-based login to unlock clues
- Show/hide password toggle
- Hidden from search engines (`noindex`)

## Built With
- HTML
- CSS
- JavaScript

The **Unlock the Treasure** event at ELECSPIRE 2026. See the [Elecspire-events](https://github.com/mansoorx1/Elecspire-events) repo.
